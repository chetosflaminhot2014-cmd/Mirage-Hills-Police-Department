# Mirage Hills Police Department

Sitio oficial de **Mirage Hills Police Department**, un simulador policial estadounidense ficticio actualmente en desarrollo.

## Sitio
La página está construida con HTML y CSS en un único archivo `index.html`, sin dependencias ni proceso de compilación.

## Estado
El proyecto está en desarrollo. No existe una descarga pública ni requisitos de sistema confirmados. La página evita presentar características planeadas como si ya estuvieran implementadas.

## Publicar con GitHub Pages
1. En el repositorio, abre **Settings**.
2. Entra en **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/(root)`, y guarda.
5. Espera a que GitHub Pages publique el sitio.
